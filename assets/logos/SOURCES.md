# Bundled logos

A small set of well-known apps, sites and AI services, shown when the system has no icon for the app and
the site's own icon cannot be fetched. Each file is the upstream file with its `<title>`, size and style
attributes removed, a 24-unit `viewBox`, and the brand's own colour (never tinted). Logos are trademarks of
their owners; they are used here only to name the app or service they stand for.

- **Simple Icons** 16.37.0, <https://github.com/simple-icons/simple-icons>, licence **CC0-1.0** (public domain
  dedication; its DISCLAIMER.md about trademarks applies). Colour = the brand hex in its `data/simple-icons.json`.
- **Lobe Icons** (`@lobehub/icons-static-svg`) 1.102.0, <https://github.com/lobehub/lobe-icons>, licence **MIT**.
  Colour = the file's own (the `-color` files), or black where the file is a single-colour mark.
