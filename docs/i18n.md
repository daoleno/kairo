# Kairo's languages

Kairo speaks English and Simplified Chinese. English is the source; every
key has both. The window follows the person's languages (the first one
Kairo has, else English), or the language Settings › General › Language
picks.

## How it works

- **The catalog** is `locales/*.yml`, in rust-i18n's format, one file per
  area, `_version: 2` (each key followed by its `en` and `zh`). NSH 0.5
  reads it for the window ([NSH i18n](https://nsh.dev/docs/i18n)); `kairo-core`
  reads the same files with rust-i18n for the rest.
- **In the window** (pages, `src/ui`, the shell, the palette), text is
  `t!("key")`, NSH's: it follows the language shown. Call it where the
  text is built; a new language builds the window again.
- **Outside the window** (the tray, notifications, the engine's messages
  and errors, the platform's toolbar and sidebar, `main.rs`), text is
  `kairo_core::tr!("key")`. The window tells `kairo-core` which language
  it shows (`kairo_core::i18n::set_language`); `kairo_core::i18n::watch()`
  says when it changes.
- **Arguments** are `%{name}`: `t!("dns.flushed_n", n = count)`. A whole
  sentence is one key with its arguments, never pieces put together: the
  word order differs.
- **Counts**: English has a `.one` and an `.other` form,
  `t!(&plural("dns.summary", n), count = n)`; Chinese gives both the same text.
- **Keys** name what the text is for (`settings.language.title`), not
  what it says. Keys are written out whole in the code (a `match` of
  literal keys, never `format!("page.{id}")`), so the tests can find them.
- **Data is not text.** What is compared in code, saved in settings,
  written into mihomo's config, sent to the controller or between Kairo and
  `kairo-server`, or read from a provider keeps its value. Show it through
  a key: the value stays, the label is translated.

`cargo test --test i18n` checks that every key has both languages with the
same `%{…}`, that every key the code names exists and every key is named,
and that no literal outside `t!`/`tr!`, logs and tests reads as English
text. A literal that must stay (a name, data) goes in
`tests/i18n-allow.txt` (file, literal, reason, tab-separated): an entry holds in its own file only.

## Writing Chinese

- Natural product Chinese, as a Chinese app would say it; not word for word.
  Short, like the English.
- Full-width punctuation in Chinese text (，。：？！（）「」), the ellipsis
  `…` as in English menus ("检查更新…").
- A space between Chinese and Latin letters or numbers: `TUN 模式`,
  `12 个节点`, `欢迎使用 Kairo`. None before or after full-width punctuation.
- Names stay as they are: Kairo, mihomo, TUN, Fake-IP, DNS, IPv6, HTTP,
  SOCKS, AI and product names (ChatGPT, Claude, Cursor, GitHub…).
- Units stay: `ms`, `KB`, `MB/s`.
