A fix to the updater. Kairo 0.1.2 and 0.1.3 install it by themselves.

### Fixed

- **Update checks survive a flaky connection to GitHub.** GitHub's download servers sometimes answer with a
  server error (HTTP 5xx). Kairo now tries again a few times before it gives up. After a check fails, the next
  one comes within minutes (10, 20, 40, … up to the usual six hours). Before, Kairo waited six hours, or for
  you to click **Check for Updates**.

### Updating

Kairo 0.1.2 and 0.1.3 download this release in the background. Click **Restart to Update** in the sidebar or
under Settings → About. Versions before 0.1.2 do not update themselves: install 0.1.4 by hand.

### Downloads

| | |
|---|---|
| macOS 11+ (Apple silicon and Intel) | `Kairo-0.1.4-macos-universal.dmg` (or `.zip`) |
| Linux x86_64 | `kairo_0.1.4_amd64.deb`, `Kairo-0.1.4-linux-x86_64.tar.gz` |
| Linux arm64 | `kairo_0.1.4_arm64.deb`, `Kairo-0.1.4-linux-aarch64.tar.gz` |

The Linux packages need GTK 4.14+ and WebKitGTK 6.0, as on Ubuntu 24.04, Debian 13, Fedora 40, Arch and later.
`SHA256SUMS` lists the checksums of every file. Every package includes the mihomo core v1.19.33.

**macOS, first open** (new installs only): the app is ad hoc signed, not notarized, so macOS stops it the
first time. Open Kairo once, then go to System Settings → Privacy & Security and click **Open Anyway** next
to Kairo. Or run `xattr -dr com.apple.quarantine /Applications/Kairo.app` before opening it.
