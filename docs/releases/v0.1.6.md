Connect works every time, and connects sooner. Kairo 0.1.2 to 0.1.5 install it by themselves.

### Fixed

- **"Port in use" no longer stops Connect.** If another program (often another Clash client, which uses the
  same ports) holds Kairo's proxy port, Kairo moves to the next free port, points the system proxy there and
  keeps it. Home says so in one line: "Port 7897 is used by verge-mihomo, so Kairo is on 7898." If no free
  port is near, it names the program to quit.
- **Turning Connect off and straight back on** always ends connected. Kairo waits for its own core to stop
  before it starts the next one, and the last click wins.
- **A subscription's own DNS port** (often 7874) no longer collides with another client running the same
  subscription. Kairo moves it to a free port, and the subscription's DNS settings follow.
- **The first Connect is quicker.** Kairo connects through the first place that answers and finds the fastest
  one in the background. The GeoIP data the core needs is downloaded when Kairo opens, from whichever mirror
  answers first, so Connect no longer waits for a download from GitHub.
- **Force quitting Kairo no longer leaves the computer offline.**
  - If Kairo crashes or is force quit, a small helper puts the system proxy back.
  - If the helper is killed as well, the core keeps running so the proxy still works. The next Kairo stops it.
  - A login item, **Kairo network check**, puts the system proxy back at the next login if the proxy it
    points to is gone. On macOS 13 and later it shows as a background item.
- **A dead proxy is never put back.** If the system proxy pointed at a local port that no longer answers
  when you connected (another client's leftover), Disconnect turns the proxy off instead of restoring it.

### Changed

- **Kairo never cuts open connections.** Changing Location (automatically or by hand) or Route used to close
  connections. Now they finish on the place they started on: a long AI answer or a download keeps going, and
  new connections take the new place. To move everything at once, use **Close All** in Connections.
- **If your proxy port moved**, anything set to the old port by hand (a shell's `https_proxy`, a browser
  extension) needs the new one. It is under Settings → Proxy → Proxy port.

### Updating

Kairo 0.1.2 to 0.1.5 download this release in the background. Click **Restart to Update** in the sidebar or
under Settings → About. Versions before 0.1.2 do not update themselves: install 0.1.6 by hand.

`SHA256SUMS` lists the checksums of every file. Every package includes the mihomo core v1.19.33.

**macOS, first open** (new installs only): the app is ad hoc signed, not notarized, so macOS stops it the
first time. Open Kairo once, then go to System Settings → Privacy & Security and click **Open Anyway** next
to Kairo. Or run `xattr -dr com.apple.quarantine /Applications/Kairo.app` before opening it.
