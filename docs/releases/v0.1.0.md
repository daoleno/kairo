The first release of Kairo, a native desktop client for the mihomo proxy core on macOS and Linux.

### What's in it

- **Core management**: Kairo downloads the official mihomo build and checks it against the published SHA-256.
  It can update the core and start, stop or restart it, and it restarts the core after a crash.
- **Profiles**: subscription URLs or YAML files, with scheduled and manual updates, usage and expiry, one-click
  switching, and a per-profile overrides editor. The core validates every change before Kairo applies it.
- **Proxies**: groups, node selection, delay tests (per node or per group), sorting, filtering, and proxy
  providers with update and health check.
- **Modes**: Rule, Global and Direct.
- **System proxy**: on macOS, GNOME and KDE. The previous settings come back on quit, on a signal, after a
  crash and even after a SIGKILL.
- **TUN**: one switch, with a one-time privilege grant that applies to the core alone.
- **Live views**: traffic graph, connections (fast with thousands of rows), rules, logs and memory.
- **Also**: a DNS lookup tool, settings, and a tray / menu bar item with status, mode, system proxy, TUN, node
  switching and speeds.
- Follows the system's light or dark appearance.

### Downloads

| | |
|---|---|
| macOS 11+ (Apple silicon and Intel) | `Kairo-0.1.0-macos-universal.dmg` (or `.zip`) |
| Linux x86_64 | `kairo_0.1.0_amd64.deb`, `Kairo-0.1.0-linux-x86_64.tar.gz` |
| Linux arm64 | `kairo_0.1.0_arm64.deb`, `Kairo-0.1.0-linux-aarch64.tar.gz` |

The Linux packages need GTK 4.14+ and WebKitGTK 6.0, as on Ubuntu 24.04, Debian 13, Fedora 40, Arch and later.
`SHA256SUMS` lists the checksums of every file.

**macOS, first open**: the app is ad hoc signed, not notarized. The first time, right-click Kairo in
Applications and choose **Open**, then **Open** again. Alternatively, run
`xattr -dr com.apple.quarantine /Applications/Kairo.app`.

Kairo does not include mihomo. It downloads the core on first run.
