Kairo now runs on Windows and Android as well: the same five pages on a phone as five tabs, and on Windows in a window with a tray icon. Flags are pictures everywhere. Kairo 0.1.2 and later on macOS and Linux update themselves.

### New

- **Kairo for Android.** Sideload the APK (below). Home, Exits, Activity, Apps and Subs are the five tabs, Settings is the gear at the top right of Home. Kairo is its own VPN: the first time you press **Connect**, Android asks for notifications (13+) and then for the VPN permission. Activity and Apps & Sites are lists, not tables, and everything the desktop window can do is there. Updating: **Update to 0.3.1** downloads the release, Android asks you to confirm, and Kairo does not reopen by itself afterwards: tap the notification "Kairo was updated" to open it again. If an update fails (for instance a different signing key) Home says why and offers **Try Again**.
- **Kairo for Windows** (10 and 11, 64-bit, unsigned). Apps follow the system settings (Windows' per-user proxy, put back when you switch off, quit or if Kairo is killed). Tray icon, close to tray, start at login, tools that ignore the system proxy are detected and **Copy for Terminal** gives PowerShell lines. The **Download** button at the bottom left updates it. Not in this release: **Every app** (TUN) and WSL traffic.
- **Flags are pictures** on every platform (Twemoji, CC-BY 4.0; credit in Settings › About), because Windows has no flag emoji.
- On a phone the charts say **Tap** where the desktop says "Move over", and a tap picks the column.

### Fixed

- A notice on a page (for instance "Copied") could stay on screen for good when you left the page before its timer ran out.
- A downloaded update only counts if it is the file the manifest names.
- The exit picker marks the current choice.

### Good to know

- Android: **arm64 phones with Android 9 or later only.** Only the VPN path exists (no system-proxy mode). Not in this release: always-on/lockdown handling, a quick-settings tile, per-app VPN.
- Android installs from a downloaded file: Android may ask you to allow installs from your browser or file manager, and Google Play Protect may ask about an app it has not seen. Kairo is signed with its own key, the same one for every release (certificate SHA-256 `95d8456a40eac46549f4dba6f6a26181612e724c229a397f2a46515de67c80f6`; check it with `apksigner verify --print-certs`).

### Updating

Kairo 0.1.2 and later on macOS and Linux: click **Restart to Update** (or **Download** first). Windows and Android: see above.

`SHA256SUMS` lists the checksums of every file. Every package includes the mihomo core v1.19.33.

**Windows says "Windows protected your PC".** This build is **not code-signed yet**, so Microsoft Defender SmartScreen shows "Unknown publisher" the first time you run the installer or `kairo.exe`. That message means Windows has not seen the file before. To continue: **More info → Run anyway**. Check the download first if you like: `SHA256SUMS` lists every file, and the in-app updater verifies an ed25519 signature before it installs anything. If you downloaded the `.zip`, right-click it → Properties → Unblock before unpacking. Some antivirus tools warn about unsigned programs that change proxy settings; Kairo does that on purpose (it is a proxy client). If yours objects, tell us which tool and message.

**macOS, first open** (new installs only): the app is ad hoc signed, not notarized, so macOS stops it the first time. Open Kairo once, then go to System Settings → Privacy & Security and click **Open Anyway**. Or run `xattr -dr com.apple.quarantine /Applications/Kairo.app` before opening it.
