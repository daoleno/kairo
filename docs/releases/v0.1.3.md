A small release, and the first one that Kairo 0.1.2 installs by itself.

### Changed

- Settings → About now shows when Kairo last checked for updates ("Kairo is up to date · checked at 14:05").

### Updating

Kairo 0.1.2 downloads this release in the background. Click **Restart to Update** in the sidebar or under
Settings → About. Earlier versions do not update themselves: install 0.1.3 by hand.

### Downloads

| | |
|---|---|
| macOS 11+ (Apple silicon and Intel) | `Kairo-0.1.3-macos-universal.dmg` (or `.zip`) |
| Linux x86_64 | `kairo_0.1.3_amd64.deb`, `Kairo-0.1.3-linux-x86_64.tar.gz` |
| Linux arm64 | `kairo_0.1.3_arm64.deb`, `Kairo-0.1.3-linux-aarch64.tar.gz` |

The Linux packages need GTK 4.14+ and WebKitGTK 6.0, as on Ubuntu 24.04, Debian 13, Fedora 40, Arch and later.
`SHA256SUMS` lists the checksums of every file. Every package includes the mihomo core v1.19.33.

**macOS, first open** (new installs only): the app is ad hoc signed, not notarized, so macOS stops it the
first time. Open Kairo once, then go to System Settings → Privacy & Security and click **Open Anyway** next
to Kairo. Or run `xattr -dr com.apple.quarantine /Applications/Kairo.app` before opening it.
