Kairo for AI work: your AI tools go out through one exit that stays put, and Kairo shows what each service sees. Kairo 0.1.2 to 0.1.6 install it by themselves.

### New

- **AI exit.** Claude, ChatGPT, Gemini, Cursor, Copilot, Perplexity and Grok go out through one server, and stay on it when the Location changes by itself. Home has an **AI exit** row to pick another. A subscription that already has its own AI group keeps where it goes today: that server becomes the exit. If the pinned server leaves your subscription, Home says so and AI follows the Location until you pin another. Moving the exit never closes an open connection.
- **AI on Home.** A tile for each service: the country it sees, and the tools using it. Open a tile for what Kairo measured:
  - **Reachable** through the exit.
  - **API** answers, and how fast (asked without a key, so the answer is the service's "who are you?", not a model call).
  - **Country** the service sees. This comes from Cloudflare's trace when the service is behind Cloudflare, and is marked "estimated" when it is not. One server can look like different countries to different services, and Kairo says so when they differ.
  - A connection **held open for 90 seconds**.

  The checks run when you connect and every ten minutes (the 90-second hold once an hour, or when you press **Check again**). Kairo shows what the service sees; where you are and the service's own terms still apply.
- **Activity.** A new page: tools on the left, the AI exit in the middle, services on the right. A line is as thick as the traffic it carries and dashed when it stays off the exit. Counts only: tool, service, bytes. No addresses, no content. Connections is one click below ("All connections").
- **Domestic AI goes direct.** Kimi, DeepSeek, Doubao, Tongyi, Zhipu, Hunyuan, MiniMax and Wenxin skip the proxy. **Local models are never proxied:** Ollama, LM Studio and anything on your own network stay on this computer.
- **Downloads follow the Location.** Hugging Face, PyPI, PyTorch, Ollama, Docker and GitHub release downloads go through the Location, not the AI exit.
- **All Traffic keeps AI where it is.** The route used to hand everything, AI included, to the Location. It is now your rules with the Location as the rest, and AI stays on its exit.
- **Settings → AI** turns each part off: the AI exit, domestic AI direct, downloads. Turning the AI exit off puts every rule of Kairo's away and leaves your subscription as it was.

### Changed

- **Fewer things to read.** Settings keeps what people use, and the rest is under **Advanced** (ports, LAN, IPv6, bypass list, controller, secret, TUN stack, delay test, custom core). Removed: the 90-second traffic line on Home (Activity replaces it), the "Start the core with Kairo" switch (the Connect switch on Home does that), the New Secret button, the Task row, the data folder path (the Open Data Folder button stays), the route in the sidebar footer, and the GeoIP button (⌘K → Update GeoIP and GeoSite). The subscription's AI group is on Home, not in Apps & Sites. DNS is a search away: ⌘K → **Go to DNS**.
- **Shortcuts moved.** ⌘2 is Activity; Apps & Sites, Groups, Subscriptions, Connections, Rules and Logs are ⌘3 to ⌘8. ⌘8 used to be DNS.

### Good to know

- **The AI layer is on after you update.** Right after connecting and every ten minutes, Kairo makes a few small requests to the seven services through the exit (their website and API addresses, with no key and no account), and once an hour one of them stays open for 90 seconds. Settings → AI → "AI tools use one exit" turns it all off.
- **The core now reads process names** (`find-process-mode`), so Activity can say which tool a connection comes from. Names are kept as counts, in memory, and are gone when Kairo quits. A profile that sets its own mode keeps it. Where the core cannot name a process (seen on macOS 27), Kairo asks `lsof` for the owner of each local port instead.
- **Your override still comes first.** `prepend-rules` in a subscription's override go before Kairo's AI rules.
- Kairo does not change your system language or time zone, and does not tell a service anything about you.

### Updating

Kairo 0.1.2 to 0.1.6 download this release in the background. Click **Restart to Update** in the sidebar or under Settings → About. Versions before 0.1.2 do not update themselves: install 0.2.0 by hand.

**macOS, first open** (new installs only): the app is ad hoc signed, not notarized, so macOS stops it the
first time. Open Kairo once, then go to System Settings → Privacy & Security and click **Open Anyway** next
to Kairo. Or run `xattr -dr com.apple.quarantine /Applications/Kairo.app` before opening it.
