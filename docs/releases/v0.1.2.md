Kairo now ships with the mihomo core and updates itself.

### New

- **The core is included.** Every package carries the official mihomo v1.19.33 build, checked against its
  published SHA-256 when the package is built. Open Kairo and the core is running. There is no install step
  and nothing to download. Until you add a profile, traffic goes direct.
- **Automatic updates.** Kairo looks for a new release on launch and every six hours. It downloads the update
  in the background and checks it against a signed manifest and `SHA256SUMS`. When it is ready, one tap on
  **Restart to Update** installs it and reopens Kairo. The core is part of the update, so there is only one
  updater:
  - on macOS, the app is replaced in place;
  - on Linux, a `~/.local` install from the `.tar.gz` is replaced in place, and the `.deb` is installed
    through `pkexec apt-get` (one password prompt).

  The update button is in the sidebar and under Settings → About.
- **First run picks free ports.** If another client already uses 7897 or 9097, Kairo takes the next free
  ports. It never starts a core on a controller port that another program holds.

### Changed

- The Install Core button is gone. Settings → Core shows the bundled version.
- TUN's one-time grant goes to Kairo's own copy of the core, as before. If an update brings a new mihomo
  version, Kairo turns TUN off and tells you, and asks for the grant again the next time you switch TUN on.

### Downloads

| | |
|---|---|
| macOS 11+ (Apple silicon and Intel) | `Kairo-0.1.2-macos-universal.dmg` (or `.zip`) |
| Linux x86_64 | `kairo_0.1.2_amd64.deb`, `Kairo-0.1.2-linux-x86_64.tar.gz` |
| Linux arm64 | `kairo_0.1.2_arm64.deb`, `Kairo-0.1.2-linux-aarch64.tar.gz` |

The Linux packages need GTK 4.14+ and WebKitGTK 6.0, as on Ubuntu 24.04, Debian 13, Fedora 40, Arch and later.
`SHA256SUMS` lists the checksums of every file. `kairo-update.json` and its `.sig` are for the updater.

**macOS, first open**: the app is ad hoc signed, not notarized, so macOS stops it the first time. Open
Kairo once, then go to System Settings → Privacy & Security and click **Open Anyway** next to Kairo. Or run
`xattr -dr com.apple.quarantine /Applications/Kairo.app` before opening it. Updates after that need neither.

**Earlier versions do not update themselves.** Install 0.1.2 by hand once; updates are automatic from then on.
