A new design. Kairo 0.1.2 to 0.1.4 install it by themselves.

### New

- **Home** replaces Overview. One switch connects and disconnects, and the line under it says where you are
  ("Connected · Tokyo 01 · 22 ms"). Below it are three rows: Location, Route and Apps & Sites.
- **Location.** A new subscription starts on the fastest place, and Kairo checks again every ten minutes. It
  skips the provider's info entries (usage, expiry). You can also pick a place yourself: places are grouped by
  region and sorted by delay, and there is a search field.
- **Apps & Sites**: the subscription's per-app groups (streaming, AI, Telegram …), each with one choice:
  Same as Location, Direct, or a place.
- **⌘K / Ctrl+K** searches every page, action and location.
- **Errors say what to do.** A port in use gets **Use a Free Port**. A provider that sends a notice instead of
  a config gets "Your provider says: …" with **Try Again**. When an update fails, Kairo keeps using the last
  good copy and says so.
- **Linux**: a main menu in the header bar (Search Kairo…, Restart Core, Settings Ctrl+,, Quit). Kairo uses
  libadwaita's split view, and the sidebar folds away on Home.
- **A new accent** (Ember, an orange-red) on both platforms, replacing the system blue, and rounder controls.

### Changed

- **The system proxy follows Connect** for new installs. If you upgrade, your System Proxy setting stays as
  it was.
- **Upgrades keep the node you picked.** Automatic location is on only for new installs. You can turn it on
  in Settings → General → Choose the location automatically, or pick Fastest under Location. If the node in
  use is one of the provider's info entries, Kairo still moves to the fastest place.
- **Advanced pages**: Groups (was Proxies), Subscriptions (was Profiles), Connections, Rules, Logs and DNS
  sit in the sidebar under Advanced. Nothing was removed.
- **Page shortcuts** follow the new order: ⌘/Ctrl+1 Home, 2 Apps & Sites, 3 Groups, 4 Subscriptions,
  5 Connections, 6 Rules, 7 Logs, 8 DNS.
- **Modes are called Routes**: Smart, All Traffic and Direct (mihomo's Rule, Global and Direct).
- **Tray**: Connect, Location (Fastest and the 15 quickest places), Route, Open Kairo and Quit. System Proxy,
  TUN and Start/Stop Core are no longer in the tray: System Proxy and TUN are in Settings, and Connect starts
  and stops the core.
- **Settings**: "Tray quick switch" is now **Locations from**, the group Kairo picks places in. **Automatic**
  picks the group most others follow.
- **Core memory** is shown at the bottom of Connections.

### Fixed

- **A provider's notice is no longer reported as "Not valid YAML".** Some providers answer with a plain-text
  notice when their fetch window is closed. Kairo used to report it that way in a toast that disappeared, and
  it now shows the notice itself. A failed scheduled update is retried every hour; before, Kairo stopped
  trying after the first failure.

### Updating

Kairo 0.1.2 to 0.1.4 download this release in the background. Click **Restart to Update** in the sidebar or
under Settings → About. Versions before 0.1.2 do not update themselves: install 0.1.5 by hand.

The Linux packages need GTK 4.14+ and WebKitGTK 6.0, as on Ubuntu 24.04, Debian 13, Fedora 40, Arch and later.
`SHA256SUMS` lists the checksums of every file. Every package includes the mihomo core v1.19.33.

**macOS, first open** (new installs only): the app is ad hoc signed, not notarized, so macOS stops it the
first time. Open Kairo once, then go to System Settings → Privacy & Security and click **Open Anyway** next
to Kairo. Or run `xattr -dr com.apple.quarantine /Applications/Kairo.app` before opening it.
