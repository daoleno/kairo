A fix release. Upgrading is recommended, especially if you use Kairo next to another proxy app.

### Fixed

- **Quitting Kairo no longer turns off a system proxy it did not set.** In 0.1.0, quitting, or stopping Kairo
  with a signal, switched the system proxy off on macOS, GNOME and KDE even when Kairo's own System Proxy had
  never been on. That cleared the settings of another proxy app, such as one already listening on
  127.0.0.1:7897. Kairo now only puts back what it saved when it turned its System Proxy on; otherwise it
  leaves the system proxy as it is. With Kairo's System Proxy on over another app's proxy, quitting still
  restores that app's settings.

The Linux packages need GTK 4.14+ and WebKitGTK 6.0, as on Ubuntu 24.04, Debian 13, Fedora 40, Arch and later.
`SHA256SUMS` lists the checksums of every file.

**macOS, first open**: the app is ad hoc signed, not notarized, so macOS stops it the first time. Open
Kairo once, then go to System Settings → Privacy & Security and click **Open Anyway** next to Kairo. Or run
`xattr -dr com.apple.quarantine /Applications/Kairo.app` before opening it.

Kairo does not include mihomo. It downloads the core on first run.
